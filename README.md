# The Chronicle

A premium editorial WordPress-inspired news blog and publishing demo built for high-traffic content brands, technical journalism, and magazine-style storytelling.

## Overview

The Chronicle presents a refined editorial experience with:

- magazine-style homepage layout
- category navigation and topic filtering
- article detail pages with rich typography
- cache and performance telemetry panels
- WordPress-inspired admin interface
- responsive design for desktop and mobile reading

## Tech Stack

- React + Vite + TypeScript
- Express API mock for WordPress-style endpoints
- Custom MySQL-inspired data layer
- Tailwind-based editorial styling

## Local Setup

Prerequisites: Node.js 18+

1. Install dependencies:
   `npm install --legacy-peer-deps`
2. Start the app:
   `npm run dev`
3. Open the frontend in your browser:
   `http://localhost:5173/`

> In environments where port 3000 or 5173 is already occupied, the app may automatically use the next available port.

## Production Build

```bash
npm run build
```

## Notes

This project is designed as a premium showcase for a WordPress news blog experience and is suitable for presentation, demo, and marketplace-ready editorial use.
